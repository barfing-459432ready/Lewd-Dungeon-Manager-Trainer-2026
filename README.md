## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Lewd Dungeon Manager 🔞**. This trainer provides optional quality-of-life controls for dungeon management and progression. It can modify available resources, accelerate construction and training, protect the player during encounters, and simplify character development while leaving the game's dungeon-management loop intact.

**Target Audience:** For adult PC players who already own Lewd Dungeon Manager and want a more relaxed way to manage the dungeon, develop characters, complete encounters, or replay content without extended resource and timer grinding. The game contains explicit adult content and is intended for adults only.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Movement takes place through the game's dungeon-management and encounter interfaces rather than a conventional open-world navigation system. Select the desired room, activity, or event from the available management screens, then use the trainer only after the relevant action is visible. Keep resource and instant-action options disabled when beginning a new activity if you want the original progression pace.

### Tools & Inventory

Use the inventory and management screens to review the items and resources required for dungeon development and character progression. Activate the resource option after the inventory or management interface has loaded, perform the desired purchase or upgrade, and verify the updated value before leaving the screen. Save normally after completing a session and avoid repeatedly spending or generating large values.

### World & Environment

The core loop revolves around expanding and improving the dungeon, assigning activities, developing its inhabitants, and responding to adventurer-related events. Instant construction and training are most useful when the corresponding action is already queued or selected. Complete ordinary management actions before enabling another option so the game can register each change correctly.

### Combat & Weapons

Enter an encounter normally and wait until the combat interface is fully loaded before enabling combat options. Unlimited health protects supported allies, while unlimited action resources reduces the cost of supported abilities. Easy Victory is intended for encounters that are already in progress. Turn combat options off before returning to management screens, advancing story events, or closing the game.
